# Try the Variant Reconciliation System

The public demo uses replacement editorial content and condenses the original review into four component groups. It opens on the overview. Select **Open review** to enter the board.

## A short walkthrough

1. In **Sources**, open a document preview and add a source note. The preview supports Previous, Next and keyboard navigation.
2. In **Decisions**, select an opening and choose **Approve**. Select several callouts in the multi-selection component and approve them together.
3. To retain an item with context, write a decision note and choose **Approve**. To remove supporting material, choose **Exclude component**. If no alternative is suitable, choose **None of these** and add instructions. Attach a file or add a link for an alternative, then select **Approve**. Without a reference, this choice remains pending. You can also accept an existing option or exclude the component. Each group also supports reference files and web links.
4. Visit **Approved summary** to inspect the selections and notes. **Activity** shows the recorded actions.
5. Resolve all four groups. A group is resolved when it is approved or excluded. Once all groups are resolved, selection controls are locked.
6. In **Text QA & Export**, inspect the selected text against its source preview. Edit if necessary and confirm each applicable Text QA checkbox. Editing after confirmation clears that confirmation.
7. Export the approved content package. Notes and exclusions are included. You remain in the export view after downloading.

## Important distinctions

- **Approve** keeps the selected content, any note and its references together. A link typed into the reference field is included when approving. **None of these** can be approved once an alternative file or link is supplied. Reference-only approvals have no extracted source text to confirm in Text QA.
- Multiple compatible passages can be retained together. The exported text is concatenated with separators; there is no automatic editorial merge.
- Content approval does not approve layout, typography or print readiness.
- Reviewer and Producer are demonstration labels, not authenticated accounts.
- Both labels use the same review in the same browser. Other browsers do not share its data.

## Start again

Choose **Reset demo** and confirm. This clears only the demo’s stored decisions and notes. It does not affect any original project or client records.

## Reference files and links

Attach files or paste a web link in a component’s reference controls. References appear in the summary and producer view. Files are stored locally in this browser and can be downloaded separately; the Markdown includes their names and the reference links.
